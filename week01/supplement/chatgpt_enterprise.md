# UCSF ChatGPT Enterprise

## What is UCSF ChatGPT Enterprise?

UCSF ChatGPT Enterprise is a **data-secure, user-private AI platform** powered by OpenAI's models, deployed specifically for the UCSF community. It is available on web, iOS, and Android.

The key difference from a personal ChatGPT account: **your conversations are private and UCSF data stays protected.** ChatGPT Enterprise supports HIPAA compliance and is approved for use with P3 and P4 UCSF data classifications.

> Do not use personal ChatGPT, Google Gemini, or other public AI tools with UCSF data or patient information. Use ChatGPT Enterprise instead.

---

## Why use it in this course?

AI tools can be genuinely useful for learning to code and doing data analysis. Specifically, ChatGPT Enterprise can help you:

- **Understand error messages** — paste an error from R and ask for a plain-language explanation
- **Learn functions you haven't seen before** — ask how a function works and see an example
- **Brainstorm analysis approaches** — describe your dataset and research question and get suggestions
- **Understand statistical output** — paste model output and ask for an interpretation

> **Important:** AI tools can produce plausible-looking incorrect code. Always run the code yourself and verify that the output makes sense. Never copy-paste without understanding what the code does.

## How to get access

1. Complete the required training: [UCSF SPARK-AI Foundations course](https://ai.ucsf.edu/ucsf-spark-ai-foundations)
2. Request access via the form (you must attest to completing training within 60 days)
3. Log in: [ChatGPT Enterprise FAQs — Access and Login](https://ai.ucsf.edu/ucsf-chatgpt-enterprise-faqs#paragraph-2271)

---

## Data and privacy

- ChatGPT Enterprise is approved for P3 and P4 UCSF data
- Chats are retained for 90 days — see the [data and privacy FAQ](https://ai.ucsf.edu/ucsf-chatgpt-enterprise-faqs#paragraph-2276) for details
- Responsible use policies still apply — the tool does not change what data you are allowed to use
