# R and RStudio

## What are R and RStudio?

**R** is a programming language designed for statistical computing and data analysis. It is free, open-source, and widely used across biomedical research, epidemiology, and data science. When you write R code, you are giving a computer a precise set of instructions — and R carries them out.

**RStudio** is an Integrated Development Environment, or **IDE**. Think of it this way:

> R is the engine. RStudio is the dashboard.

You need both installed on your computer. R does the computing; RStudio gives you a comfortable environment to write, run, and organize your code.

---

## The four panes of RStudio

When you open RStudio, you will see four panes:

| Pane | What it does |
|------|-------------|
| **Console** (bottom left) | Where R runs your code and shows output |
| **Script editor** (top left) | Where you write and save R scripts |
| **Environment** (top right) | Shows all objects currently in memory |
| **Files / Plots / Help** (bottom right) | Browse files, view plots, read documentation |

You will spend most of your time in the Script editor and Console.

---

## R or Python?

Both are excellent languages for data science. Our recommendation: **choose the one your colleagues and mentors use.** For biomedical research at UCSF, R is common — especially for statistical analysis and clinical data.

> **Pro tip:** Learn one language well before starting a second. Once you have mastered R, picking up Python will be much easier.

## Knowledge check

**True or False:** RStudio is a programming language used for data science and statistical applications.

<details>
<summary>Answer</summary>

**False.** R is the programming language. RStudio is an IDE — software that makes it easier to write and run R code. They are different tools that work together.

</details>
